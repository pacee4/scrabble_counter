# [Подсчёт очков в Эрудите](https://pacee4.github.io/scrabble_counter)

Это приложение берёт от «лучшего» счетовода ответственность за подсчёт, запись очков и написание слов и заменяет блокнот, калькулятор и орфографический словарь.

Как во всех репозиториях данного пользователя, итоговый отображаемый проект написан на русском языке, однако в техническом процессе реализации используется английский язык.
- Содержит около 10% кода, сгенерированного ИИ
